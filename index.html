WHAT IS
CAPYBARA?

Project Capybara is a real, live implementation on the X1 Network. It is the delegation program's fair stake threshold system — the engine that determines which validators qualify for Foundation delegation every epoch.

Project Capybara is a real protocol deployed on X1 blockchain mainnet. It was specified by Jack Levin (Cyphereus Prime) on May 1st.

$CAPPY is a separate community meme coin. It takes its name and spirit from the protocol but has no official connection to it. The community made a meme because the name was too good. That's the whole story.

Without a fair threshold, the delegation program could be gamed. Validators with tiny self-stake could receive outsized Foundation delegation — earning rewards far disproportionate to their actual skin in the game.

Capybara closes that exploit. Every epoch it recalculates the 85th percentile of all active validator self-stakes and sets that as the minimum bar. Only validators with real capital on the line qualify. Dynamic. Transparent. Verifiable on-chain.

"The p85 method ensures the threshold is always representative of real validator commitment — not a static number that becomes stale as the network evolves."

HOW IT WORKS

THE EPOCH
MECHANISM

Four steps. Every epoch. Fully automatic. Unstoppable.

01
COLLECT

Every epoch, Capybara collects self-stake amounts from all active validators currently running on X1.

02
CALCULATE

Computes the 85th percentile (p85) of the complete stake distribution. This becomes the threshold.

03
THRESHOLD

Validators with self-stake ≥ the p85 value pass this check and become eligible for Foundation delegation.

04
RECALIBRATE

Repeats every epoch as stake amounts shift. Never static — always live and representative.

// capybara_runtime — epoch execution loop

fn run_epoch(validators: Vec<Validator>) {
  let stakes = collect_self_stakes(&validators);
  let p85 = percentile(&stakes, 85); // CAPYBARA

  for v in validators {
    if v.self_stake >= p85
      && v.commission <= 0.10
      && v.vote_credits >= 0.97
      && v.skip_rate_ok() // within ±10% avg
      && v.tachyon_majority() {
        grant_delegation(&v);
    }
  }
}

◈

◈
VOTE CREDITS
