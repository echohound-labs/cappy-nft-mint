PROTOCOL BRIEF

WHAT IS
CAPYBARA?

Capybara is the X1 Network's fair stake threshold system — the immune system of the delegation program. It calculates the 85th percentile of all active validators' self-stake amounts each epoch, setting the minimum stake required to qualify for Foundation delegation.

Without a fair threshold, the delegation program could be gamed. Validators with tiny self-stake could receive outsized Foundation delegation — earning rewards disproportionate to their actual skin in the game.

Capybara ends that. It ensures only validators with real capital at risk receive delegation privileges. No free rides. No exploits. Only commitment gets rewarded.

"The p85 method ensures the threshold is always representative of real validator commitment — not a static number that becomes stale as the network evolves."

MECHANISM

HOW IT
WORKS

Four steps. Every epoch. Automatic. Unstoppable.

01
COLLECT

Every epoch, Capybara collects self-stake amounts from all active validators on the X1 network.

02
CALCULATE

The system calculates the 85th percentile (p85) of that full stake distribution.

03
THRESHOLD

Validators with self-stake ≥ the p85 value become eligible for Foundation delegation.

04
RECALIBRATE

Re-evaluates each epoch as stake amounts shift. The threshold is never static — always live.

// capybara_runtime.rs — epoch execution

fn run_epoch(validators: Vec<Validator>) {
  let stakes = collect_self_stakes(&validators);
  let p85 = calculate_percentile(&stakes, 85);

  for v in validators {
    if v.self_stake >= p85
      && v.commission <= 0.10
      && v.vote_credits >= 0.97
      && v.skip_rate_ok()
      && v.running_tachyon_majority() {
        delegate(&v); // ELIGIBLE
    }
  }
}
FULL CRITERIA

DELEGATION
REQUIREMENTS

Capybara handles the stake side. But validators must meet all five criteria to receive Foundation delegation.

◈
SELF-STAKE
P85
Must meet or exceed the 85th percentile of all active validator self-stakes. Recalculates every epoch.
◈
COMMISSION
≤10%
Maximum commission rate allowed. Ensures validators aren't extracting excessive fees from delegators.
◈
VOTE CREDITS
≥97%
Minimum vote credit score required. Proves the validator is actively participating in consensus.
◈
SKIP RATE
±10%
Skip rate must stay within 10% of the network average. No lagging validators getting rewards.
◈
TACHYON
MAJORITY
Must run the majority Tachyon version. Keeps the network on the latest and strongest software.
